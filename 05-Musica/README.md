# Música - Mistery House

## Composiciones
Cada uno de los 4 NPCs cuenta con una **canción-trauma** original que forma parte de su narrativa.

## Especificaciones de Audio
- **Formato**: WAV/OPUS para calidad de streaming
- **BPM**: Ajustable según dificultad
- **Duración**: 2-4 minutos por canción
- **Género**: Música instrumental, ambiental, narrativa

## Estructura Rítmica (4 carriles)
