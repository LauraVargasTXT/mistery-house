# Proyecto Unity - Mistery House

## Configuración
- **Versión**: Unity 2022.3 LTS
- **Plataformas**: PC, Web (WebGL)

## Sistemas Principales
1. **Sistema de Ritmo** (4 carriles - UI interactiva)
2. **Sistema de Diálogo** (Visual Novel style)
3. **Sistema de Decisiones** (Impactan en la narrativa)
4. **Mindfulness Sessions** (25 minutos sin distracciones)

## Estructura de Escenas
- Menu Principal
- Selección de Personaje / NPC
- Casa Musical (escena hub)
- Minijuegos de Ritmo (4 escenarios)
- Resultado / Relación aumentada
