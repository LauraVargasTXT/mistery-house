# Modelado 3D - Mistery House

## Assets a Crear
- **Casa Musical** (5 habitaciones)
- **Protagonista** (1 personaje jugable)
- **NPCs** (4 personajes)
- **Escenarios de Canción** (4 escenas musicales)
- **Props** (20 elementos decorativos)

## Especificaciones Técnicas
- Motor: Blender 5.0
- Texturizado: Substance Painter (2K PBR)
- Shaders: Toon Shader + PBR en Unity 2022.3 LTS
- Formato: FBX/GLTF para exportación

**Semanas 2-8**: Modelado base
**Semanas 9-12**: Texturizado PBR
**Semanas 13-15**: Animación e integración
